# PlotTwist

## Overview

PlotTwist is an interactive quiz web application where users determine whether statements about celebrities are true or false. The game ensures variety by tracking previously shown questions, preventing repetition.

## Tech Stack

- **Frontend:** Next.js  
- **Backend:** Express.js  
- **Database:** Supabase  
- **Deployment:** Render (backend), Vercel (frontend), Docker
